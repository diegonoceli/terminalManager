# Quickstart: Drag & Drop, Paste and Clickable Links

## Testing Drag and Drop
1. Start the app: `npm start`.
2. Open a terminal.
3. Open Windows File Explorer (or macOS Finder).
4. Drag a folder with spaces in its name (e.g. `C:\Program Files` or `My Project`) and drop it onto the terminal.
5. Notice the terminal highlights when hovering over it, and upon drop, the quoted path appears inserted in the prompt.

## Testing Clickable Links
1. In the terminal, type `echo https://github.com` or start a local dev server printing `http://localhost:3000`.
2. Hover over the link: notice the cursor changes to pointer / underline.
3. Click (or Cmd/Ctrl+Click) the link: the URL will immediately open in your default browser.

## Testing Paste
1. Copy any text or path to clipboard.
2. In the terminal, press `Ctrl+V` (Windows) or `Cmd+V` (Mac), or right-click: the clipboard text is pasted.
